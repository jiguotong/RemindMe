功能 01
🕐
实时时钟
主界面中央显示当前日期（含星期）和时间（时:分:秒），每秒刷新，液晶字体风格，配熊猫动态图。

日程清单
左侧面板，支持添加 / 删除 / 勾选完成。支持三级优先级：高（红色背景）/ 普通（绿色）/ 低（灰色）。勾选后自动添加删除线。
CORE

⏰

右侧面板，按时间排序。支持 h:mm 和 hh:mm 两种格式输入。到时弹窗 + 循环报警音，时间不能早于当前时刻。

§ 03

界面布局

三列布局 · 全屏
主窗口结构
窗口分为三个纵向列区，随窗口尺寸等比缩放：

左列（25% 宽）：日程清单标题 + CheckBox 列表 + 添加/删除按钮

中列（50% 宽）：日期标签 + 时间标签（液晶字体）+ 熊猫动态图

右列（25% 宽）：闹钟表格（时间 | 内容双列）+ 添加/删除按钮
辅助区域
左侧抽屉（隐藏式）：点击边缘红色竖条展开，含声音开关、置顶、透明度三项设置，500ms 动画滑入。

底部按钮栏：贴窗口底部，两侧分别放日程操作（添加/删除）和闹钟操作（添加/删除），中间留空展示时钟。
提醒弹窗 · MyDialog
闹钟到时弹窗
弹窗宽 450px，含图标 + 提醒内容 + 三个交互区：

· Close：关闭弹窗并停止报警音
· 分钟数微调器（1–60 min）+ Snooze：延迟重新提醒
· Enter / Esc：键盘快速关闭

弹窗出现时主窗口自动从托盘还原到前台。
添加日程对话框 · DlgTasks
输入框 + 优先级下拉菜单（High Priority / Normal / Low Priority）+ 确定/取消。打开时焦点自动落在输入框。
添加闹钟对话框 · DlgClocks
时间输入框（支持 9:37 或 09:37）+ 内容输入框 + 确定/取消。校验不能早于当前时间，打开时焦点自动落在时间框。
§ 04

快捷键

键盘操作全覆盖
快捷键 作用域 功能
Ctrl + Q 主窗口 添加日程——打开 DlgTasks 对话框
Ctrl + W 主窗口 删除日程——删除当前选中且已勾选的日程
Ctrl + E 主窗口 添加闹钟——打开 DlgClocks 对话框
Ctrl + R 主窗口 删除闹钟——删除当前选中行的闹钟
Delete 日程列表 / 闹钟表格 键盘删除——焦点在列表时删除日程，焦点在表格时删除闹钟
Enter / Esc 提醒弹窗 关闭弹窗——停止报警音并关闭提醒窗口
§ 05

设置面板

左侧抽屉 · 点击展开
设置 01 · 提示音
声音开关
图标按钮切换提示音开 / 关。同步与托盘菜单的 Mute/Unmute 联动，状态一致。默认开启，音量 25%，WAV 循环播放。
设置 02 · 置顶
Always On Top
点击切换窗口是否始终在最前方显示。适合将 RemindMe 作为常驻桌面工具使用，不被其他窗口遮挡。
设置 03 · 透明度
Opacity 滑块
拖动滑块调节窗口透明度，范围 20%–100%，实时生效。适合多窗口叠加工作场景，避免完全遮挡其他内容。
快捷操作 · 一键清空
清空按钮（🗑）同时删除全部日程 + 停止所有闹钟计时器 + 清空闹钟表格，操作前有二次确认弹窗。
面板动画
点击窗口左侧红色竖条展开设置面板（500ms 滑入动画）；点击面板内收起按钮折叠（100ms 快速收回）。
§ 06

数据持久化

JSON · 自动读写
存储位置
数据文件路径：
%AppData%\RemindMe\remindme_data.json

由 Qt QStandardPaths::AppDataLocation 自动确定，无需手动配置。
保存时机
点击关闭按钮 → 确认退出 → 先保存数据再退出。数据包含所有日程（文本 + 优先级颜色 + 勾选状态）和全部闹钟（时间 + 内容 + 重复模式）。
恢复逻辑
启动时自动恢复
日程：按原顺序 + 优先级颜色恢复，勾选状态一并还原。

闹钟：根据当前时间重新计算剩余毫秒，重新 startTimer：
· 单次且已过期 → 自动跳过
· 重复模式且已过期 → 推算下一次触发时间后恢复
JSON 结构
{ "tasks": [...], "clocks": [...] }

每条 task 含 text / checked / priority（颜色值）；每条 clock 含 time / content / repeat。
§ 07

技术栈 & 架构

Qt5 · MSVC · x64
模块 职责 关键信号 / 接口
Mainwindow 主窗口，协调全部功能；闹钟数据存储于 QVector<ClockNode>；布局由 repositionWidgets() 在 resizeEvent 中动态计算 timerEvent / recMsg / recQStr / saveData / loadData
DlgTasks 添加日程对话框；用户输入文本和优先级后确认 emit SendText(text, priority)
DlgClocks 添加闹钟对话框；校验时间格式和非过去时间约束 emit sendMsg(time, content)
MyDialog 闹钟触发提醒弹窗；支持关闭和 Snooze 两种响应 emit signalSnooze(minutes) / signalMyDialogBtnCloseClicked()
ClockNode 闹钟数据结构，存于 QVector，替代原手写链表 字段：timerId / time / content / repeat
构建 Build · Qt 5.14.1 MSVC2017 x64 RELEASE CONFIG
构建工具
MSBuild v18 + Qt/MSBuild 3.4.1 + Visual Studio BuildTools 2022
编码约定
编译器标志 /utf-8（已写入 .vcxproj）；.cpp/.h 文件中不写中文字符串，统一用英文或 QString::fromUtf8()
输出产物
x64/Release/RemindMe.exe，单实例保护（QSharedMemory），有效期校验（180天）
§ 08 · 一句话总结

RemindMe 是一款全屏自适应、数据持久化、支持重复闹钟与 Snooze 的 Windows 桌面提醒工具，以三列布局同屏呈现日程清单、实时时钟与闹钟管理，系统托盘常驻、置顶透明度可调，适合需要轻量、始终可见的日程提醒场景。
